# STEP5: Create a HTML Page into Nginx and Restart Nginx

## Overview
This step covers creating an HTML page and deploying it to nginx, then restarting the nginx service.

### Steps Overview

2. Create an HTML page
3. Deploy the HTML to nginx web root directory
4. Restart the nginx service
5. Verify the website is accessible
